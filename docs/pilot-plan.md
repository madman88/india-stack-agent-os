# Pilot Plan

## Buyer

Start with lenders, NBFCs, ONDC seller apps, POS platforms, or CA/accounting platforms. Do not start with direct kirana sales as the primary GTM path.

## Pilot Promise

Agentic working-capital monitoring and execution support for MSMEs:

- faster underwriting
- cheaper post-disbursement monitoring
- better timing for repeat credit
- transparent owner approval
- verifiable proof chain for regulated workflows

## Design Partner Criteria

Target partners should have:

- access to MSME transaction or sales data
- appetite for working-capital automation
- ability to run a sandbox or limited pilot
- one internal operator who owns the workflow
- legal/compliance willingness to review consent and approval logs

## First Pilot Flow

1. Ingest sample MSME cashflow, inventory, and obligation data.
2. Generate a working-capital recommendation.
3. Explain the recommendation to the owner.
4. Capture approval or rejection.
5. Prepare simulated PO, repayment mandate, and settlement instruction.
6. Export proof chain for partner review.

## Evidence To Collect

- time saved per underwriting or monitoring decision
- recommendation acceptance rate
- exceptions caught before disbursement
- proof-chain completeness
- operator trust and override rate
